# Канал о смыслах в моде

Собирает мировую модную ленту (индустрия, производство, культура), находит сюжеты, в которых частность открывает смысл, пишет пост в голосе канала и присылает черновик вам в Telegram. Публикуется только то, что вы одобрили.

```
RSS (26 лент) → дедуп и кластеры → отбор (Haiku 4.5) → смысл (Opus 5) → текст (Opus 5)
   → черновик вам в бота → ✅ очередь / 🚀 сейчас / ✏️ правка / ⏸ / ✖️ → канал по расписанию
```

## Запуск

1. **Бот.** В Telegram откройте @BotFather → `/newbot` → получите токен.
2. **Канал.** Добавьте бота в канал администратором с правом «Публикация сообщений».
3. **Настройки.** `cp .env.example .env`, заполните `DATABASE_URL`, `ANTHROPIC_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHANNEL_ID` (`@username` канала).
4. **База и зависимости.**
   ```bash
   npm install
   createdb channel
   ```
5. **Ваш id.** `npm start`, напишите боту `/start` — он пришлёт chat id. Впишите его в `TELEGRAM_OWNER_CHAT_ID`, перезапустите.

После этого бот сам собирает ленту каждые 6 часов и присылает до 3 черновиков.

Посмотреть, что попадает в отбор, без генерации постов: `npm run collect`.

## Что настраивать в первую очередь

| Что | Где |
|---|---|
| Голос канала, структура, запреты | `style/guide.md` |
| **Образцы ваших постов** (сильнее всего влияют на качество) | `style/examples/01.md`, `02.md`… |
| Линзы и логика «частность → смысл» | `src/prompts.js` |
| Источники | `src/sources.js` |
| Частота, порог оценки, часы публикации | `.env` |

## Форматы по дням

Каждый день недели — свой формат поста (`src/formats.js`): Пн «Слова тренда», Вт «Материал и производство», Ср «Одна вещь — разные смыслы», Чт «Теория на примере», Пт «Как менялся код», Сб «Психология стиля», Вс «Приёмы». У формата своя структура и свои образцы из `style/examples`.

Черновики готовятся в формате дня ближайшего слота публикации (вечером — уже завтрашнего). В слот публикуется одобренный пост формата дня, а если такого нет — самый старый одобренный.

## Команды бота

`/run` — прогон сейчас · `/formats` — расписание · `/queue` — очередь · `/deferred` — вернуть отложенные · `/cancel` — отменить правку.

«✏️ Править» → напишите одним сообщением, что изменить → придёт новая версия.

## Как устроено

- `collect.js` — RSS; закрытые издания (BoF, Vogue Business, FashionUnited, Ecotextile) — через Google News с фильтром по домену. Вакансии и гороскопы отсекаются.
- `cluster.js` — одна новость из разных изданий склеивается в сюжет (пересечение слов заголовков). Сюжет из нескольких источников и сюжеты из производственного слоя получают бонус при отборе.
- `pipeline.js` — отбор → разбор (`fact / detail / shift / frame / general / reader_turn / thesis`) → текст. Разбор хранится отдельно от текста: правка переписывает текст, не пересобирая смысл.
- Память: последние 40 тезисов идут в промпт разбора — модель отбрасывает повторы. Линзы трёх последних постов штрафуются, чтобы канал не зацикливался.
- Ссылки на источники дописываются кодом, а не моделью: они не могут быть выдуманы.
- Для Opus 5 включён серверный fallback (`fallbacks: "default"`): при ложном отказе классификатора запрос сам перезапускается на другой модели.

## Что дальше

- Эмбеддинги вместо пересечения слов — точнее склеивать сюжеты и ловить смысловые повторы.
- Telegram-каналы как источники — через клиентский API (GramJS), бот их читать не может.
- Обложка: типографический шаблон в Cloudinary с тезисом поста.
- Просмотры и реакции → раз в месяц лучшие посты уходят в `style/examples`.
